# Lost and Found Portal

## Project Overview
Lost and Found Portal is a web-based application developed to help users report lost and found items and submit claims for missing belongings.

## Technologies Used
- Java
- JSP (JavaServer Pages)
- Jakarta Servlets
- JDBC
- Oracle Database
- HTML
- CSS
- Apache Tomcat 11

## Features
- User Registration
- User Login and Logout
- Report Lost Items
- View Reported Items
- Report Found Items
- Submit Claims
- User Dashboard
- My Claims and Reports

## Database
Oracle Database 23ai

The database SQL scripts are available in the `database` folder.

## Server
Apache Tomcat 11

## Project Structure
- `src/main/java` – Java Servlet classes and database connectivity
- `webapp` – JSP pages and web resources
- `database` – Oracle SQL scripts
- `WEB-INF` – Web application configuration and libraries

## How to Run
1. Install JDK 21 or a compatible JDK.
2. Install Apache Tomcat 11.
3. Configure Oracle Database.
4. Add the Oracle JDBC driver.
5. Configure the database connection in DBConnection.java.
6. Deploy the application on Tomcat.
7. Open the application in your browser.
